FAQ

Does it work in Chrome? Yes, same package. Chrome Web Store review is pending; you can load it unpacked for now.

Does it upload my files secretly? No. The extension requests a single permission, storage, and declares no network hosts.

Encrypted PDFs? Not supported — decrypt first.

Can it compress scans? Yes: compression re-encodes the embedded images. Text-only PDFs barely shrink (they are already small).

Can I get an invoice? Yes, a Chinese invoice (个体户) is available on request.
